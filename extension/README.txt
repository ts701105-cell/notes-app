雲筆記網頁剪輯 (Chrome / Edge 擴充套件) v1.1

安裝:
1. 解壓縮這個資料夾。
2. 在 Chrome 網址列輸入 chrome://extensions ,開啟右上角「開發人員模式」。
3. 按「載入未封裝項目」,選擇解壓縮後的資料夾。(更新版本時,在同一頁按該擴充套件的重新整理圖示即可)
4. 建議按拼圖圖示,把「雲筆記網頁剪輯」釘選到工具列。

使用:
- ✨ 簡化擷取(推薦):保留文字、圖片與排版(標題、清單、粗體、連結、表格),自動去掉廣告、側欄、分享按鈕與留言區。
- 純文字擷取、選取的文字、整頁截圖、畫面截圖、書籤。
- 也可以在網頁上按右鍵,選「簡化擷取本頁」。
- 剪輯會放進雲筆記的「網頁剪輯」記事本,並自動加上「網頁剪輯」標籤。
- 第一次使用需先在雲筆記登入;沒登入時剪輯會先排隊,登入後自動匯入。

權限說明:需要「讀取所有網站」權限,是為了下載文章裡的圖片並壓縮後存進筆記。
