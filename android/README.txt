雲筆記 Android App(TWA 包裝)
- APK 由 GitHub Actions 自動打包(.github/workflows/android.yml),產出放在 Releases。
- 最新版下載:https://github.com/ts701105-cell/notes-app/releases/latest/download/CloudNotes.apk
- App 打開的是 https://ts701105-cell.github.io/notes-app/,網站更新後 App 自動是新版,不必重裝。
- 想讓 App 頂端不顯示網址列:建立 repo「ts701105-cell.github.io」,把 assetlinks.json 放到 .well-known/assetlinks.json,並加上空白檔 .nojekyll。
